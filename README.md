# RoHub — сообщество любителей Roblox

Демо-сайт сообщества: личный кабинет, стена постов, группы, друзья и поиск.
Одностраничное приложение на чистых HTML/CSS/JS, без зависимостей и сборки.

## Возможности

- **Личный кабинет** — регистрация, вход, профиль (аватар, статус, био), статистика, редактирование
- **Стена** — посты с `#тегами`, лайки, комментарии, фильтры «Все / Друзья / Мои»
- **Группы** — каталог с категориями, создание своих групп, вступление/выход, стена и участники группы
- **Друзья и поиск** — добавление в друзья, поиск игроков и групп
- **Демо-данные** — 6 игроков, 10 постов, 6 групп создаются при первом запуске

## Запуск

Откройте `index.html` в браузере — сервер не нужен.
Либо через локальный сервер:

```bash
python -m http.server 8765
```

## Данные

Всё хранится в `localStorage` браузера. Демо-доступ: **BlockMaster / 123456**.

## Публикация

Сайт статический, публикуется на GitHub Pages из ветки `main`.
